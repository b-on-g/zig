# $bog_zig_demonative

Реактивная таблица в терминале на `$bog_zig_wire`, без веба. Строки читаются из stdin, каждая строка — отдельная задача рантайма, после неё тик доводит граф до покоя и вид печатает таблицу.

```sh
node bog/build2/start/-/node.js bog/zig/demonative
printf 'PRICE = 120\nQTY = 3\nTOTAL = PRICE * QTY\nQTY = 4\n' | bog/zig/demonative/-/native
```

- `NAME = формула` задаёт ячейку, `NAME =` удаляет. Формулы: числа, имена ячеек, `+ - * /`, скобки. `#` в начале строки — комментарий.
- `  calc X` в выводе — тело `value(X)` пересчиталось. Правка `QTY` пересчитывает только `TOTAL` и то, что от него зависит.
- Ошибки — значения, а не паники: `#div0`, `#syntax`, `#cycle`. Ошибка течёт в зависимые ячейки и уходит, когда причина исправлена.

## Модули

- `formula` — разбор и вычисление, без ОРП. Ссылки на ячейки отдаёт тому, кто вызвал.
- `sheet` — стор ячеек (`solid`), мемо по имени: `text`, `refs`, `value`. Цикл ищется по `refs`: они зависят только от текста, поэтому сами в цикл не попадают, а при разрыве цикла значение пересчитывается.
- корень — разбор команд и вид, `demonative.node.zig` — цикл чтения stdin.
