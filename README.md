# $bog_zig

Zig в MAM: ОРП-ядро `$bog_zig_wire` и плагин к `$bog_build2`, который собирает `.zig`-модули в нативный бинарь, `web.wasm` и гоняет `zig test`. Нужен Zig 0.17.

```sh
node bog/build2/start/-/node.js bog/zig/demo
bog/zig/demo/-/native
```

Примеры:

- `demo` — корзина: нативный бинарь, тесты и `web.wasm` с видом на $mol.
- `demonative` — реактивная таблица в терминале, без веба.

## Модули

- Модуль — папка, FQN — путь через `_`: `@import("bog_zig_demo_cart")` подключает `bog/zig/demo/cart/`. Лоадер `$bog_zig_source` видит такие импорты и тянет модуль в граф, `std` и `builtin` не трогает.
- Файлы модуля склеиваются в один Zig-файл `-/zig/<срез>/<fqn>.zig`, одинаковые `const x = @import(...)` остаются в одном экземпляре. Теги как везде: `.node.zig`, `.web.zig`, `.test.zig`.
- Бандлер `$bog_zig_bundle`:
  - `-/native`, если в модуле пака есть `pub fn main`;
  - `zig test` по всем модулям среза `node.test`, красный тест роняет сборку;
  - `-/web.wasm` (`wasm32-freestanding`, `-rdynamic`), если в модуле пака есть `export fn`.
- Плагин подключает `zig.build.ts`. Пак внутри `bog/zig` получает его сам, пак снаружи кладёт свой `*.build.ts` с `$bog_zig_source` и `$bog_zig_bundle`.

## ОРП

Свойство пишется на месте, как в моле: тело — функция анонимной структуры, первым аргументом приходит сам объект.

```zig
pub fn total(self: App) u32 {
	return self.mem.total.call(self, null, struct {
		fn body(app: App, _: ?u32) u32 {
			var out: u32 = 0;
			for (app.lines()) |line| out += line.get().sum();
			return out;
		}
	}.body);
}
```

- `Mem(T)`, `MemKey(K, T)` — атомы, лежат в поле `mem`: у поля и метода в Zig не может быть одного имени. `solid()` в теле — аналог `$mol_wire_solid()`.
- `Obj(T).make(.{ ... })` — объект, которым владеет поймавший его атом, `get()` отдаёт фасад. `Root(T)`, `Auto.make(ctx, body)` — корни графа, освобождаются `deinit()`.
- Атомы внутри структуры заводит `init`, их не перечисляют руками: `Obj(Line).make(.{ .sku = key })` заполнит `mem` сам.
- Владение как в моле: атом владеет значением целиком, внутрь срезов не заглядывает. Списки хранят ключи, объекты отдаёт фабрика `MemKey`, данные лежат в сторе.
- Значения сравниваются по содержимому и копируются атомом: срезы, структуры, опционалы. Тело возвращает что угодно — строку из `fmt`, чужое значение, литерал. Временное (`fmt`, `List`, `tmp()`) живёт до конца тика, старые значения атомов освобождаются тоже в конце тика, поэтому прочитанное значение валидно до него.
- Тик: нативно `run(ctx, body)` и `after(ctx, body)`, на вебе микротаска через `$bog_zig_wire` (TS-мост к wasm).
